                         Load Chain Configuration
                    

                

                

                    

                        Load an existing YAML chain configuration file to execute immediately.
                        This allows you to run pre-configured chains without building them from scratch.
                    


                    
Supported Features:

                    
    
                        
  • Global configuration (model, temperature, etc.)
    • 
                        
  • Multi-step prompt chains
    • 
                        
  • Pre/post processing scripts
    • 
                        
  • Per-step parameter overrides
    • 
                        
  • Multi-pass execution
    • 
                        
  • Content append mode
    • 
                        
  • Variable substitution
    • 
                    


                    
Configuration Sources:

                    
    
                        
  • Upload existing YAML files
    • 
                        
  • Use configurations from tests/ directory
    • 
                        
  • Create new configurations with YAML editor
    • 
                        
  • Export configurations from chain builder
    •

Configuration Examples

                
You can find example configurations in:

    • 
                    
  • config/ directory - Base configurations
    • 
                    
  • examples/ directory - Example chains

Required Structure

  model: "model-name"
  temperature: 0.7

input_file: input.md
output_file: output.md

    name: "step_name"
    prompt_file: "prompts/example.json"
